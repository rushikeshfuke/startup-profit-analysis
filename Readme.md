# Startup Profit Analysis

**Data Analysis Project | Multiple Linear Regression**

## About the Project

This project focuses on understanding how different business expenses are related to startup profitability. I analyzed a dataset containing 50 startup records to explore the relationship between R&D Spend, Administration, Marketing Spend, and Profit.

The main purpose of the analysis was to identify which expense factors had the strongest relationship with profit and present the findings in a clear and meaningful way.

## Project Objectives

- Understand and analyze the startup dataset.
- Explore the relationship between expenses and profit.
- Apply multiple linear regression to analyze the data.
- Identify the key factors associated with startup profitability.
- Present the findings through a Power BI dashboard.

## Dataset Overview

The dataset contains the following variables:

| Column | Description |
|---|---|
| R&D Spend | Investment in research and development |
| Administration | Administrative expenses |
| Marketing Spend | Marketing-related expenses |
| State | State of the startup |
| Profit | Profit earned by the startup |

The dataset consists of 50 records. It was extracted using SQL and exported to CSV for further analysis.

## Tools Used

- **SQL** – Data extraction
- **Microsoft Excel** – Data analysis and regression modeling
- **Power BI** – Dashboard development and visualization

## Methodology

I started by exploring the dataset and understanding the available variables. I then performed multiple linear regression in Excel, using Profit as the target variable and R&D Spend, Administration, and Marketing Spend as the independent variables.

After reviewing the regression results, I created a Power BI dashboard to visualize the key metrics and compare startup performance.

## Key Findings

The regression model achieved an **R-squared value of 95.07%**, indicating that it explains approximately 95.07% of the variation in profit within this dataset.

The analysis showed that:

- R&D Spend had a positive and statistically significant relationship with profit.
- Administration was not statistically significant at the 5% level.
- Marketing Spend was also not statistically significant at the 5% level.

Among the three expense variables, R&D Spend was the strongest predictor of profit in this dataset.
